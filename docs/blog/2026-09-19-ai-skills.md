# Stonecraft AI Agent Skill

Our times are changing fast and as engineers, we need to adapt to the new tools available to us. Stonecraft now ships with an AI agent skill that can help your agent understand both Stonecraft and the basics of Stonecutter. 

It helps to avoid mistaking the code comments as dead code and to explain the proper order of operations.

I've been pressure testing this on [InventorySorter](https://github.com/KyrptonaughtMC/Inventory-Sorter) and [SoundsBeGone](https://github.com/meza/soundsbegone) for a while now and it seems to hold up.

For more details, check out The [AI Agent Skill docs](https://stonecraft.meza.gg/docs/ai-agent-skill)
